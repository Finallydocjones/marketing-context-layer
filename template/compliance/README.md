# Compliance Standards

This folder explains the standards AlumiPlate's buyers search for and work under: what each one is, who issues it, what it requires, and how AlumiPlate relates to it.

- **`brand-facts/approvals-and-specifications.md`** records *what AlumiPlate holds*.
- **This folder** explains *what the standards are*, so Rocket55 and AI tools describe them accurately.

Load these into a **separate** Profound knowledge base ("AlumiPlate Compliance"), per Profound's guidance to keep compliance material apart from general content.

## Rules for this folder

1. **Summarize and link; don't copy.** MIL specs and U.S./EU regulations are public. ASTM, SAE (AMS), and ISO texts are copyrighted, so never paste their content.
2. **Record the revision** you checked and the date you checked it. Standards get revised; each file has a `review_by` date.
3. **Official sources first:** ASSIST (quicksearch.dla.mil) for MIL specs, acquisition.gov for DFARS, eCFR for ITAR, EUR-Lex or ECHA for EU rules, and SAE, ASTM, and ISO publisher pages.
4. Anything about what AlumiPlate *holds* must match `brand-facts/` and `policy/claims-and-restrictions.md`.
