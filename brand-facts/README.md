# brand-facts/

Canonical, dated, sourced facts about the company. Profound FactCheck checks AI answers against these.

**Required:** `company-facts.md` (identity/NAP, founding, locations, how customers buy, certifications status, "do not state" list).
**Common additions:** `approvals-and-specifications.md` (specs or approvals the client holds).

Start from `templates/brand-facts.md`. Every fact gets a source and an as-of date. Use the exact same name, address, and phone everywhere (site, schema, GBP, Bing, Merchant Center).
